# 智慧团建一键学 Bot 管理员使用说明

适用对象：团支书、组织委员、系统维护人员  
版本日期：2026-06-07  
运行状态：生产环境可用

## 1. 管理员负责什么

管理员主要负责四件事：

- 维护飞书多维表格里的学习资料和个人任务。
- 确认 Bot 能在飞书群里正常回复。
- 管理定时推送、任务提醒和数据同步。
- 必要时查看服务器状态、重启服务或排查日志。

安全提醒：

- 不要把 `.env`、`App Secret`、`Verification Token`、`ADMIN_TOKEN` 发到群里。
- 不要把真实密钥提交到 GitHub。
- 如果 Token 泄露，应在飞书开放平台重新生成，并更新服务器 `.env` 后重启服务。

## 2. 日常检查

### 2.1 检查服务是否在线

浏览器访问：

```text
http://服务器公网IP:8000/healthz
```

正常结果应包含：

```json
{
  "status": "ok",
  "env": "production"
}
```

### 2.2 检查飞书群是否能回复

在飞书群里发送：

```text
@机器人 帮助
```

如果 Bot 正常回复，说明飞书事件回调和发消息权限都正常。

### 2.3 检查服务器后台服务

服务器执行：

```bash
sudo systemctl status youth-bot
```

看到：

```text
active (running)
```

表示服务正在后台运行。

## 3. 服务器常用命令

进入项目目录：

```bash
cd /root/youth-league-feishu-bot
```

查看服务状态：

```bash
sudo systemctl status youth-bot
```

重启服务：

```bash
sudo systemctl restart youth-bot
```

查看实时日志：

```bash
sudo journalctl -u youth-bot -f
```

从 GitHub 拉取最新代码：

```bash
git pull
```

修改 `.env`：

```bash
nano .env
```

修改 `.env` 后必须重启：

```bash
sudo systemctl restart youth-bot
```

## 4. `.env` 关键配置

服务器配置文件位置：

```bash
/root/youth-league-feishu-bot/.env
```

常用配置如下：

```env
APP_ENV=production
DATABASE_PATH=./data/bot.sqlite3
ADMIN_TOKEN=你的管理接口token
ADMIN_USER_IDS=管理员open_id

FEISHU_APP_ID=cli_xxx
FEISHU_APP_SECRET=xxx
FEISHU_VERIFICATION_TOKEN=xxx
FEISHU_ENCRYPT_KEY=
FEISHU_DEFAULT_CHAT_ID=oc_xxx
```

说明：

- `APP_ENV=production`：生产环境标识。
- `ADMIN_TOKEN`：调用管理接口时使用。
- `ADMIN_USER_IDS`：允许在飞书里执行管理员指令的用户 ID，多个用英文逗号分隔。
- `FEISHU_DEFAULT_CHAT_ID`：定时推送默认发送到哪个群。

## 5. 飞书开放平台配置

在飞书开放平台中，需要确认：

- 已开启机器人能力。
- 已配置事件订阅地址。
- 已添加事件：`im.message.receive_v1`。
- 已开通发送消息、接收消息、读取用户基础信息、读取群信息等权限。
- 修改权限后，按飞书页面提示发布版本。

事件订阅请求地址：

```text
http://服务器公网IP:8000/feishu/events
```

如果后续配置域名和 HTTPS，则改成：

```text
https://你的域名/feishu/events
```

注意：

- 当前项目主要使用 `Verification Token` 校验。
- 如果没有额外开发解密逻辑，不建议开启事件加密。

## 6. 多维表格配置

服务器 `.env` 中需要配置多维表格：

```env
FEISHU_BITABLE_APP_TOKEN=多维表格app_token
FEISHU_BITABLE_WIKI_TOKEN=
FEISHU_BITABLE_MATERIALS_TABLE_ID=学习资料表tbl开头的ID
FEISHU_BITABLE_TASKS_TABLE_ID=个人任务表tbl开头的ID
```

注意：

- `TABLE_ID` 只填 `tbl...`，不要带 `&view=...`。
- 如果只维护学习资料，任务表可以暂时留空。
- 如果 `APP_TOKEN` 是 wiki 链接里的 token，必要时可改填到 `FEISHU_BITABLE_WIKI_TOKEN`。

## 7. 学习资料表维护

学习资料表建议字段：

```text
标题
分类
关键词
摘要
链接
发布日期
是否本周推荐
```

其中：

- `标题`：资料名称。
- `分类`：如法治教育、社会实践、青年工作等。
- `关键词`：多个关键词可用逗号分隔。
- `摘要`：Bot 推送时会显示。
- `链接`：资料原文链接。
- `发布日期`：用于排序。
- `是否本周推荐`：填 `是` 的资料会进入“本周学习”和定时推送。

## 8. 个人任务表维护

个人任务表建议字段：

```text
用户ID
任务标题
状态
截止日期
```

说明：

- `用户ID` 填成员的飞书 `open_id`。
- 成员可以发送 `我的ID` 获取自己的 ID。
- 状态建议统一为：`未完成`、`进行中`、`已完成`。

## 9. 同步数据

管理员在飞书里发送：

```text
同步数据
```

正常回复示例：

```text
同步完成：学习资料 4 条，个人任务 0 条。
```

如果回复 0 条，通常检查：

- `.env` 是否配置了 `FEISHU_BITABLE_MATERIALS_TABLE_ID`。
- 表 ID 是否只填了 `tbl...`，没有带 `&view=...`。
- 飞书应用是否有读取多维表格权限。
- 多维表格是否授权给应用。
- 修改 `.env` 后是否重启了服务。

## 10. 自动同步

如果希望表格改完后自动同步，在 `.env` 中开启：

```env
BITABLE_AUTO_SYNC_ENABLED=true
BITABLE_AUTO_SYNC_INTERVAL_MINUTES=10
```

含义：每 10 分钟自动从多维表格同步一次。

即使开启了自动同步，管理员仍然可以发送：

```text
同步数据
```

立即刷新。

## 11. 定时推送

定时推送配置：

```env
FEISHU_DEFAULT_CHAT_ID=oc_xxx
WEEKLY_PUSH_ENABLED=true
WEEKLY_PUSH_CRON_DAY_OF_WEEK=mon
WEEKLY_PUSH_CRON_HOUR=8
WEEKLY_PUSH_CRON_MINUTE=30
```

含义：每周一早上 8:30，向默认群推送本周学习资料。

星期写法：

```text
mon 周一
tue 周二
wed 周三
thu 周四
fri 周五
sat 周六
sun 周日
```

## 12. 立刻推送

服务器执行：

```bash
cd /root/youth-league-feishu-bot
curl -X POST "http://127.0.0.1:8000/admin/sync/bitable?token=你的ADMIN_TOKEN"
curl -X POST "http://127.0.0.1:8000/admin/push/weekly?token=你的ADMIN_TOKEN"
```

第一行：先同步多维表格。  
第二行：立刻推送本周学习资料。

## 13. 删除演示数据

如果推送里出现 `example.com`，说明本地数据库里还有演示数据。

服务器执行：

```bash
cd /root/youth-league-feishu-bot
sqlite3 data/bot.sqlite3 "DELETE FROM materials WHERE url LIKE '%example.com%';"
```

确认是否删干净：

```bash
sqlite3 data/bot.sqlite3 "SELECT title, url FROM materials WHERE url LIKE '%example.com%';"
```

没有输出就表示已删除。

## 14. 任务提醒

任务提醒配置：

```env
TASK_REMINDER_ENABLED=true
TASK_REMINDER_CRON_HOUR=9
TASK_REMINDER_CRON_MINUTE=0
TASK_REMINDER_LOOKAHEAD_DAYS=3
```

含义：每天 9:00 提醒未来 3 天内截止的未完成任务。

## 15. 常见故障

### 机器人不回复

检查：

- 事件订阅地址是否正确。
- 飞书应用权限是否开通并发布。
- 机器人是否已加入群聊。
- 服务器服务是否运行。

查看日志：

```bash
sudo journalctl -u youth-bot -f
```

### 同步数据提示没有权限

原因：你的 `open_id` 没有加入 `ADMIN_USER_IDS`。

查询最近发消息的用户 ID：

```bash
sqlite3 data/bot.sqlite3 "select user_id, raw_text, created_at from interaction_logs order by id desc limit 5;"
```

把对应 `user_id` 加入 `.env`：

```env
ADMIN_USER_IDS=ou_xxx
```

然后重启：

```bash
sudo systemctl restart youth-bot
```

### 同步完成 0 条

检查：

- `FEISHU_BITABLE_APP_TOKEN` 是否正确。
- `FEISHU_BITABLE_MATERIALS_TABLE_ID` 是否正确。
- `TABLE_ID` 是否误带了 `&view=...`。
- 飞书应用是否有多维表格读取权限。
- 表格是否授权给应用。

### 推送里还有旧资料

原因：旧资料仍在本地 SQLite 数据库里。

可删除指定旧链接：

```bash
sqlite3 data/bot.sqlite3 "DELETE FROM materials WHERE url LIKE '%example.com%';"
```

## 16. 推荐日常流程

1. 管理员在飞书多维表格维护学习资料。
2. 把本周要推送的资料设为 `是否本周推荐=是`。
3. 不想推送的旧资料改为 `否`。
4. 在飞书里发送 `同步数据`，或等待自动同步。
5. 到设定时间自动推送。
6. 如需立即推送，使用管理接口手动触发。
