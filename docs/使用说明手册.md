# 智慧团建一键学 Bot 使用说明手册

本文档分为管理员版和成员版。管理员负责维护多维表格后台、同步数据和触发提醒；成员只需要在飞书里和 Bot 对话即可。

## 一、管理员版

### 1. 日常维护入口

后台数据维护在飞书多维表格：

```text
智慧团建 BOT 后台
```

当前使用两张数据表：

```text
学习资料
个人任务
```

### 2. 维护学习资料

在“学习资料”表新增或编辑记录。

建议字段：

```text
标题
分类
关键词
摘要
链接
发布日期
是否本周推荐
```

示例：

```text
标题：青年大学习第 1 期
分类：青年大学习
关键词：青年大学习, 团课
摘要：本周团员理论学习推荐材料
链接：https://example.com
发布日期：2026/06/04
是否本周推荐：是
```

成员发送以下指令时会使用这些资料：

```text
本周学习
搜索 团课
```

`是否本周推荐` 填“是”的资料，会出现在“本周学习”里。

### 3. 给成员添加任务

先让成员给 Bot 发送：

```text
我的ID
```

成员会收到自己的飞书 `open_id`，形如：

```text
ou_xxxxxxxxxxxxxxxxx
```

管理员复制这个 ID，在“个人任务”表新增一行。

建议字段：

```text
用户id
任务标题
状态
截止日期
```

示例：

```text
用户id：ou_xxxxxxxxxxxxxxxxx
任务标题：完成青年大学习截图提交
状态：未完成
截止日期：2026/06/10
```

状态建议统一使用：

```text
未完成
进行中
已完成
```

### 4. 同步数据

Bot 使用本地数据库缓存多维表格数据。因此管理员修改多维表格后，需要同步一次，Bot 才能读取最新内容。

管理员在飞书中给 Bot 发送：

```text
同步数据
```

正常回复示例：

```text
同步完成：学习资料 3 条，个人任务 5 条。
```

如果开启了自动同步，则不必每次手动同步，等待自动同步即可。着急时仍然可以发送“同步数据”立即刷新。

### 5. 任务提醒

任务提醒会给临近截止且状态不是“已完成”的成员发送单聊提醒。

当前支持管理员手动触发接口：

```text
POST /admin/remind/tasks?token=change-me&days=3
```

也可以在 `.env` 中开启每日自动提醒：

```text
TASK_REMINDER_ENABLED=true
TASK_REMINDER_CRON_HOUR=9
TASK_REMINDER_CRON_MINUTE=0
TASK_REMINDER_LOOKAHEAD_DAYS=3
```

含义：

```text
每天 9:00 提醒未来 3 天内截止的未完成任务。
```

### 6. 成员完成任务后的状态回写

成员不需要打开多维表格。

成员发送：

```text
完成任务 1
```

或：

```text
完成任务 任务关键词
```

Bot 会把该任务状态写回多维表格：

```text
已完成
```

如果写回失败，通常检查：

```text
1. 飞书开放平台是否开通 base:record:update 或 bitable:app 权限
2. 多维表格是否添加了文档应用
3. 文档应用是否有可编辑权限
4. 权限修改后应用是否已重新发布
```

### 7. 临时隧道注意事项

当前使用 Cloudflare 临时隧道。每次隧道重启后，回调地址可能变化。

新地址形如：

```text
https://xxxx.trycloudflare.com/feishu/events
```

如果地址变了，需要在飞书开放平台修改：

```text
事件与回调 -> 事件配置 -> 订阅方式 -> 请求地址
```

只修改事件请求地址，一般不需要重新发布应用，保存即可。

## 二、成员版

### 1. 查看帮助

给 Bot 发送：

```text
帮助
```

Bot 会返回可用指令列表。

### 2. 查看自己的 ID

第一次领取任务前，给 Bot 发送：

```text
我的ID
```

Bot 会回复你的飞书 `open_id`。把这个 ID 发给管理员，管理员才能在任务表里给你分配任务。

### 3. 查看我的任务

给 Bot 发送：

```text
我的任务
```

Bot 会返回你的任务列表，例如：

```text
你的团务任务：
1. 完成青年大学习截图提交 [未完成]，截止：2026-06-10
```

### 4. 完成任务

如果只有一条任务，或你知道任务序号，可以发送：

```text
完成任务 1
```

也可以按任务关键词完成：

```text
完成任务 青年大学习
```

成功后 Bot 会回复：

```text
已将任务标记为已完成：完成青年大学习截图提交
```

### 5. 查看本周学习

给 Bot 发送：

```text
本周学习
```

Bot 会返回管理员设置为“本周推荐”的学习资料。

### 6. 搜索资料

给 Bot 发送：

```text
搜索 团课
```

或：

```text
搜索 青年大学习
```

Bot 会根据标题、关键词、摘要查找学习资料。

### 7. 活动报名

给 Bot 发送：

```text
活动报名 春季团课
```

Bot 会记录你的报名信息。

### 8. 常见问题

可以直接提问，例如：

```text
团课怎么补
```

如果 Bot 的 FAQ 中已有答案，会直接回复。

## 三、常用指令汇总

管理员常用：

```text
同步数据
```

成员常用：

```text
帮助
我的ID
我的任务
完成任务 1
本周学习
搜索 团课
活动报名 春季团课
团课怎么补
```

## 四、维护建议

建议日常使用流程：

```text
1. 管理员在多维表格维护学习资料和个人任务
2. 管理员发送“同步数据”
3. 成员发送“我的任务”查看任务
4. 成员完成后发送“完成任务 1”
5. Bot 自动写回多维表格状态
6. 管理员定期查看多维表格和周报
```
