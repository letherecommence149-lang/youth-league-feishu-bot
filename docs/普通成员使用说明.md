# 智慧团建一键学 Bot 普通成员使用说明

适用对象：团员、普通成员  
版本日期：2026-06-07  
使用入口：飞书群聊或机器人单聊

## 1. 这个 Bot 可以做什么

你可以用它：

- 查看本周学习资料。
- 搜索团课、青年大学习、社会实践等资料。
- 查看自己被分配的团务任务。
- 完成任务后直接在飞书里标记完成。
- 报名活动。
- 询问常见问题。

## 2. 基本使用方式

在群聊里，一般需要先 `@机器人`，再输入指令。

例如：

```text
@机器人 帮助
```

如果是和机器人单聊，可以直接输入：

```text
帮助
```

## 3. 第一次使用

第一次使用建议先做两件事。

### 3.1 查看帮助

发送：

```text
@机器人 帮助
```

Bot 会返回可用指令列表。

### 3.2 获取自己的 ID

发送：

```text
@机器人 我的ID
```

Bot 会返回你的飞书 `open_id`，类似：

```text
ou_xxxxxxxxxxxxxxxxx
```

把这个 ID 发给管理员，管理员才能在任务表里给你分配个人任务。

## 4. 常用指令

| 指令 | 用途 | 示例 |
|---|---|---|
| 帮助 | 查看可用功能 | `@机器人 帮助` |
| 我的ID | 查看自己的飞书 open_id | `@机器人 我的ID` |
| 我的任务 | 查看分配给自己的任务 | `@机器人 我的任务` |
| 完成任务 1 | 按序号完成任务 | `@机器人 完成任务 1` |
| 完成任务 关键词 | 按关键词完成任务 | `@机器人 完成任务 青年大学习` |
| 本周学习 | 查看本周推荐资料 | `@机器人 本周学习` |
| 搜索 关键词 | 搜索资料 | `@机器人 搜索 团课` |
| 活动报名 活动名 | 报名活动 | `@机器人 活动报名 春季团课` |
| 周报 | 查看团务统计 | `@机器人 周报` |

## 5. 查看我的任务

发送：

```text
@机器人 我的任务
```

Bot 会返回你的任务列表，例如：

```text
你的团务任务：
1. 完成青年大学习截图提交 [未完成]，截止：2026-06-10
```

如果没有任务，可能是：

- 管理员还没有给你分配任务。
- 你还没有把 `我的ID` 发给管理员。
- 管理员刚修改表格，但还没有同步数据。

## 6. 完成任务

如果知道任务序号，发送：

```text
@机器人 完成任务 1
```

如果不记得序号，也可以输入任务关键词：

```text
@机器人 完成任务 青年大学习
```

成功后，Bot 会回复类似：

```text
已将任务标记为已完成：完成青年大学习截图提交
```

建议：

- 任务少的时候，用序号最快。
- 任务多的时候，先发 `我的任务` 查看列表。
- 关键词尽量使用任务标题里的明显词语。

## 7. 查看本周学习资料

发送：

```text
@机器人 本周学习
```

Bot 会返回管理员设置为“本周推荐”的学习资料，包括：

- 标题
- 摘要
- 链接

如果没有返回资料，可能是管理员还没有设置本周推荐。

## 8. 搜索资料

发送：

```text
@机器人 搜索 团课
```

也可以换成其他关键词：

```text
@机器人 搜索 青年大学习
@机器人 搜索 社会实践
@机器人 搜索 法治教育
```

搜索会根据资料的标题、分类、关键词和摘要匹配。

## 9. 活动报名

如果管理员发布了活动，可以发送：

```text
@机器人 活动报名 春季团课
```

Bot 会记录你的报名信息。

报名时建议写清楚活动名称，避免和其他活动混淆。

## 10. 常见问题

你可以直接向 Bot 提问，例如：

```text
@机器人 团课怎么补
@机器人 忘记提交截图怎么办
@机器人 如何报名活动
```

如果资料库里有答案，Bot 会直接回复。

如果没有答案，可以：

- 换一个关键词搜索。
- 联系管理员补充 FAQ。
- 等待人工处理。

## 11. 收不到回复怎么办

可以按顺序检查：

1. 是否已经 `@机器人`。
2. 指令和关键词之间是否有空格，例如 `搜索 团课`。
3. 机器人是否已经加入当前群聊。
4. 等几秒再试一次，服务器可能正在重启。
5. 仍然无回复时，把截图和发送时间发给管理员。
